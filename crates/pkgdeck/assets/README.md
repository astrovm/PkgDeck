# Bundled artwork

`logo.svg` is a copy of the repository's application icon
(`assets/io.github.astrovm.PkgDeck.svg`), used by the README screenshots.
`logo-64.png` is the window icon. The app draws its logo itself, in the
accent colour. `logo-template.svg` is the same cube in black with shaded
faces, and `logo-template.png` its raster form for the macOS menu bar, which
tints it to match light and dark menu bars.

# Fonts

The styles draw with fonts free to share, each with its license beside it:

- `Inter-*.ttf`: Inter, for the Modern style (`Inter-LICENSE.txt`, SIL OFL 1.1).
- `W95FA.otf`: W95FA by Alina Sava, after Windows 98's MS Sans Serif
  (`W95FA-LICENSE.txt`, SIL OFL 1.1). `W95FA-Bold.ttf` is made from it,
  each glyph a pixel thicker, as Windows drew its bold.
- `Selawik-*.ttf`: Selawik by Microsoft, drawn to stand in for Segoe UI
  (`Selawik-LICENSE.txt`, SIL OFL 1.1).
